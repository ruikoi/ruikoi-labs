# 新项目模板

[English](README.md) | 简体中文

复制本目录为 `projects/<project-name>/`，填写：

1. 项目目标、实现内容、源码仓库及准确提交；不要只写浮动分支名。
2. Linux/macOS 支持范围与主机依赖。
3. build.sh、run.sh、test.sh 的用法和输入产物。
4. smoke、完整应用和可选性能测试的成功条件。
5. 已完成、待验证、明确不支持的内容。
6. 实际截图／架构图及其来源；日志生成的运行图应明确标为摘录，并区分功能模拟与 RTL 验证范围。
7. 英文 `README.md` 与中文 `README.zh-CN.md`，互相链接并同步维护命令和支持范围。

源码修改留在对应 fork；产物留在被忽略的工作目录；不要提交机器地址、用户名路径、SSH 配置或密钥。
